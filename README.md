# Java-Practice-Programs
This repository holds a long array of different types of Java programs to demonstrate and practice my knowledge of the Java language and its logic to develop high quality, good practice programs--following the challenge problems from "Starting Out With Java" by Tony Gaddis, and additional practice given by instructors at my time at CPCC.

The "Chapters 1-4" branch demonstrates programs highlighting the fundamentals of the Java language (how to display text, use different types of variables and arithmetic operations, etc.), the various decision structures, and loops with the introduction of files.
